1.What is the difference between var, let, and const?<br>
Ans: var, let, and const are used to declare variables in JavaScript, but they behave differently.<br>
var: Declares variables with function or global scope and allows re-declaration and updates within the same scope.<br>
let: Declares variables with block scope, allowing updates but not re-declaration within the same block.<br>
const: Declares block-scoped variables that cannot be reassigned after their initial assignment.<br>

3.What is the difference between map(), filter(), and forEach()?<br>
Ans:<br>
map(): Creates a new array by modifying each element.<br>
filter(): Creates a new array with elements that match a condition.<br>
forEach(): Runs a function for each element in the array.It does not return a new array.<br>
